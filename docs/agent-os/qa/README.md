# QA

The qa-tester agent's runs (`.claude/agents/qa-tester.md`, `/agent-os qa`).

- `YYYY-MM-DD-qa.md`: the build tested, the journey table, bugs with
  steps, accessibility and speed notes.
- `shots/`: screenshots of failures. Tester data only; another player's
  name is cropped out.

P1 and P2 bugs go to `../backlog.md` as `S<n>` items, checked by
support-triage. Signed-in journeys run in local sessions only (the tester
account is in the founder's Chrome).
