# Design

The designer agent's work (`.claude/agents/designer.md`, `/agent-os design`).

- `YYYY-MM-DD-<topic>.md`: a design proposal (problem, directions, the
  recommended mockup, the spec, the checks) or a review of another agent's
  screen or graphic.
- `mockups/`: static HTML mockups using the app's Tailwind classes, and
  PNG exports. Made-up or tester data only.

Screen changes go to the builder as `D<n>` items in `../backlog.md`. The
design rules themselves live in `docs/design.md`, changed only after the
founder approves. The visual trend board is `../trends/visual.md`.
