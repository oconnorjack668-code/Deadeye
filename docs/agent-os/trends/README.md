# Trends

What is popular right now, refreshed every week, so the agents work from
this season and not from memory. Founder's ask, 2026-11-11: the video
editor and marketing should know what is working on TikTok now, and the
designer what looks good to young players.

| File | Kept by | What | Read by |
| --- | --- | --- | --- |
| `ads.md` | marketing (Thursdays) | TikTok and Instagram: top sports and app ads this week (TikTok Creative Center Top Ads, Meta Ad Library for rival training apps), trending sounds and hashtags in basketball and sport, formats and hooks that are working | video-editor, designer, player-outreach |
| `visual.md` | designer | Basketball visual culture and app design: type, colour, layout, motion, badges, share cards, with what Deadeye takes from each | marketing, video-editor, builder |

Rules for both:
- Newest first, each line dated with its source link. Under 80 lines:
  replace old lines rather than adding.
- A trend is a principle to adapt, never a copy: no one's footage, artwork,
  logo or audio is lifted. Sounds are used only from the platform's own
  library when posting (founder).
- Refresh when the file is more than 7 days old (`ads.md`) or 14 days
  (`visual.md`), or when a task needs it.
- Counts and public sources only; no person's details.
