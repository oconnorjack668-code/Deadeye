# D4 setup for Irish players (2026-11-24)

Agent: Claude Code, Opus 5.5 (builder) · Commits: 897c4ae · PR: #168 (not merged) · Status: in progress (review)

## Outcome
Setup (`/onboarding`) built as drawn in `docs/agent-os/design/2026-11-23-setup.md`. It has its own slim header with no Navbar or tab bar, "Step n of 3", and a fixed footer with a full-width Next or Finish. It uses Irish/UK words, starts in centimetres, and has 44 px chips. The age brackets are now 13-15 / 16-17 / 18+: a 13 to 15 sign-up is not asked again, and a 16-or-older sign-up picks "16 or 17" or "18 or older". Every reader of `age_bracket`, in the app and in the database, now reads both old and new values.

## Decisions
- Two migrations instead of one. 00068 allows the new values and updates the DB rules, so it is safe with the old code. 00069 backfills and runs only after the new code is live. With a single file the backfill would land while the old code was live, and that code reads 16-17 as "not a minor" in coach setup and club entries. (builder; founder OKs before any run)
- In the backfill, the younger reading wins when the sign-up answer and the old bracket disagree, and 14-17 with no sign-up answer becomes 13-15. (builder, for safety-reviewer to confirm)
- Units start metric for a new account, and a saved value wins only once setup is finished. `measurement_system` defaults to imperial in the table (00010), so every new row already says imperial. (builder)
- Leaderboard age bands are now U16, 16-17 and 18+. The old 14-17 stays its own band until 00069. (builder)
- New `app_events` marker `setup_started` for the Signal step. (builder)
